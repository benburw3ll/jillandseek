# Jill and Seek

A lost-dog finder for Minnesota.

When a dog goes missing, the people looking for it check many sites by hand, again and again: shelter stray lists, lost-pet databases and neighbourhood posts. Jill and Seek gathers every Minnesota source it is allowed to read into one place, ranks each listing against the missing dog and says why. A match is a ranking, never an identification: go and see the dog in person. It runs on the owner's own computer first, is free to use, and reads only what a site allows.
